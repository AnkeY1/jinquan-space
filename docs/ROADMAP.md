# Beyond V1

These are future ideas, not current features:

- Add approved personal education, experience and real project/publication records.
- Add owner-supplied photography or music with local assets and explicit licenses.
- Extend CSV datetime support only after defining timezone/format rules and tests.
- Add more browser-local tools with dedicated algorithms, resource limits and fixtures.
- Consider multilingual content or richer search after content volume justifies it.
- Backend computation, accounts or cloud saving require a new privacy and authorization design; they cannot retain the current local-only claims unchanged.

No empty navigation entries or placeholder product features are shipped for these ideas.
